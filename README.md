# Сравнение моделей классификации

Учебный микротест LightGBM, CatBoost и XGBoost на одном синтетическом датасете. Скрипт измеряет время обучения, время получения вероятностей и ROC-AUC на отложенной выборке.

## Запуск

Проверено с Python 3.13 и пакетами из `requirements.txt`:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

Для быстрой локальной проверки:

```powershell
.\.venv\Scripts\python main.py --samples 1000 --estimators 5
```

На Linux/macOS используйте `.venv/bin/python` вместо пути через `Scripts`.

Генерация данных и разделение на обучение/тест имеют фиксированное зерно случайности; в тестовой выборке сохраняется доля классов. Каждая модель получает одинаковое число деревьев и один поток. Время зависит от процессора и версии библиотек; сравнение не подбирает гиперпараметры и не является универсальным рейтингом моделей. Датасет полностью искусственный, внешние данные не загружаются.
